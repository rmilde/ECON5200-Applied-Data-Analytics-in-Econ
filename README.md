# ECON5200-Applied-Data-Analytics-in-Econ

Welcome! I'm a graduate student studying Applied Data Analytics in Economics (ECON 5200). This repository showcases my work bridging traditional economic theory with modern data science techniques.

## About This Portfolio
This repository contains coursework and labs where I'm learning to combine causal inference with predictive analytics. The course follows a "Concept Extension" approach—we start with foundational statistical concepts (like OLS regression) and scale them up using machine learning algorithms (like Lasso and Ridge regression).
I'm developing skills to answer both "why" questions through econometric methods and "what" questions through predictive modeling, making me versatile in tackling real-world economic problems.
